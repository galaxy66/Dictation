# Dictation

Empty starter projects:

- `frontend/`: React with Vite. Run `npm install`, then `npm run dev` from this folder.
- `backend/`: ASP.NET Core API targeting .NET 10. Run `dotnet run` from this folder with the .NET 10 SDK installed.

No features, endpoints, database configuration, or Docker files are included.
PostgreSQL integration can be added when the data model is defined.
